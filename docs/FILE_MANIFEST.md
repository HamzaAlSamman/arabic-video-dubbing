## التمييز بين الأصل والمستجد

- **الدفاتر، الأوزان، وملفات PDF:** النقل فقط، بدون تغيير المحتوى.
- **README.md:** وثيقة جديدة تعكس النطاق الحالي وتزيل ادعاءات غير مثبتة في التوثيق القديم.
- **docs/** و **.gitignore:** ملفات توثيق وتنظيم جديدة، ليست نتائج بحثية.
- دفاتر Colab قد تحتوي روابط داخلية قديمة للمسار السابق؛ هذه **ملاحظة توافق** بسبب حفظ البايتات الأصلية، ولا تعني تغيير إعداداتها أو خوارزمياتها.
- إذا لزم تعديل الدفاتر لاحقًا، احفظ نسخة مشتقة جديدة بدل استبدال الأصل.
