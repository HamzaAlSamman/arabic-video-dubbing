- الدفتران الخاصان بالدبلجة لا يعبران بالضرورة عن قرار التصميم الأحدث، وبعض وظائفهما (مثل diarization) **خارج النطاق الحالي**.

## الحالة البحثية

| المجال | الحالة الحالية |
|---|---|
| فيديو إنجليزي → فيديو مدبلج عربي | تجربة قديمة في تخرج 1؛ لا تُعلن جودة End-to-End دون فحص المخرجات |
| فصل الكلام عن الضجيج | دفتر تجارب + وزن محفوظ؛ يلزم التحقق من البيانات والتقسيم والنتائج |
| تفريغ الكلام والمحاذاة | مكونات WhisperX موجودة في دفاتر قديمة |
| الترجمة العربية | دمج خدمات/نماذج موجود في تجارب قديمة؛ تقييم المصطلحات لم يثبت بمنهجية موحدة |
| TTS | توجد بدائل في دفاتر قديمة؛ اختيار الإنتاج النهائي لم يُحسم |
| مزامنة الشفاه | توجد تهيئة/كود قديم؛ نجاح النتيجة النهائية غير مثبت |
| مجموعة بيانات معيارية | غير موثقة/غير معتمدة |
| نتائج Baseline وAblation | غير موثقة/غير معتمدة |
| تكاليف الأداء والتراخيص | تحتاج دراسة قبل الاستخدام التجاري |

## محاذير مهمة

- لا نستنتج نجاح أداة من ذكرها في Notebook فقط.
- لا نعتبر ملف `best_model.pth` نموذجًا متحققًا من جودته دون توثيق الأصل والإصدار والاختبار.
- لا ننسخ أو ننشر أسرار الوصول أو تسجيلات الفيديو المرخّصة دون تصريح.
- لا نعيد تشغيل تدريب، ASR، ترجمة، توليد صوت، API مدفوع أو GPU تلقائيًا.
- يمنع الخلط بين العمل **المنفذ سابقًا** وخطة تخرج 2 أو خطة البحث الحالية.
